# arcade-3d-racing

Дизайн аркадной гонки
Идея игры
Аркадная 3D-гонка с камерой за машиной. После входа по логину и паролю игрок выбирает один из двух режимов — сетевой заезд на двоих или одиночный заезд на лучшее время.
Режимы игры
Сетевой заезд. Первый игрок создаёт комнату, задаёт ей название и выбирает настройки заезда. Второй игрок находит комнату в списке открытых комнат и подключается через интернет. Когда оба игрока загрузили трассу, начинается общий отсчёт. Игроки видят машины друг друга на трассе. Побеждает тот, кто первым пересекает финишную линию.
Заезд на лучший результат. Игрок проезжает трассу на время. После финиша он видит время заезда. Его лучший результат сохраняется в таблице рейтинга, где можно сравнить своё время с результатами других игроков.
Трасса
В первой версии для обоих режимов будет одна трасса со стартом и финишем в разных местах. На развилке игрок выбирает один из двух путей, которые снова сходятся перед финишем. На дороге будут ускоряющие полосы и препятствия. Полоса на несколько секунд увеличивает скорость, а столкновение с препятствием замедляет машину.
Пейзаж продолжается за пределами дороги. Например, трасса может идти вдоль моря, а с дороги будут видны горы и здания. Ограждения и рельеф удерживают машину в пределах маршрута.
Машина и управление
На телефоне игрок управляет газом, тормозом и поворотом с помощью экранных кнопок. Для компьютера предусмотрено управление с клавиатуры.
Техническая реализация
Интерфейс и вход
Интерфейс на Vue и TypeScript включает экран входа по логину и паролю, экран выбора режима, список комнат, экран результата и таблицу рейтинга.
Сетевой заезд и результаты
Игровой сервер будет доступен через интернет. Он хранит список открытых комнат, синхронизирует старт и движение машин, фиксирует порядок финиша в сетевом заезде и сохраняет лучшие времена одиночных заездов для таблицы рейтинга.
Запуск игры
Игру можно будет открыть по ссылке в браузере на компьютере и телефоне. Для сдачи упакуем веб-версию с помощью Electron в исполняемый файл .exe. При запуске файла игра откроется в отдельном окне приложения.
Команда
Команда вместе готовит диздок. Дальше задачи меняются по этапам, чтобы каждый поработал над механикой, трассой, интерфейсом и сервером.
Этап 2. Прототип
Михаил — разгон, торможение и пробный участок трассы.
Женя — создание комнат и общий старт на сервере, список комнат в меню.
Ваня — развилка на трассе и проверка контрольных точек на сервере.
Ульяна — поворот машины и кнопки управления на телефоне.
Этап 3. Полная версия
Михаил — вход по логину и паролю на сервере и экран входа.
Женя — ускорение машины на полосах и размещение препятствий.
Ваня — столкновения машин, экран результатов и рейтинг.
Ульяна — окружение трассы, передача движения машин и запись рекордов.
Этап 4. Перекрёстная проверка
Михаил — сборка .exe и проверка управления на телефоне.
Женя — столкновения машин и порядок финиша.
Ваня — вход в аккаунт и запуск заезда из комнаты.
Ульяна — отображение комнат и обновление таблицы рекордов.
Вместе проверяем оба режима в браузере и запуск сборки .exe.
